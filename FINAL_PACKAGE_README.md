# Shade final app package

This ZIP contains the Shade project with all changes applied.

Included:

- pitch-black monochrome settings UI,
- neural prediction integration,
- English ONNX model,
- Hindi baseline ONNX model,
- Hinglish baseline ONNX model,
- English/Hinglish/Hindi neural vocabularies,
- motion polish,
- crash/jank hardening,
- organized language packs under `app/src/main/assets/languages/`,
- patch notes and crash audit.

Build:

```bash
./gradlew assembleDebug
```
